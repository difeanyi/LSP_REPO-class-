# CRC Card Explanation – Library Lending System

Library collaborates with Book because its CRC responsibilities ("maintain books," "coordinate borrowing/returning," "retrieve books by criteria") can only be fulfilled by asking Book objects for their details and telling them to change state. Book lists no collaborators because its responsibilities ("store book information," "maintain availability," "validate borrowing/returning") concern only its own data, so it never needs to know which library holds it. Keeping this one-way dependency means Book stays simple and reusable, for example as a standalone book borrowed directly. The three-book limit is enforced by Library because it is a rule about the collection as a whole, and only Library tracks how many of its books are borrowed at once. A single Book only knows its own availability and cannot count other borrowed books, which is why "enforce borrowing limit" appears on the Library card rather than the Book card.
